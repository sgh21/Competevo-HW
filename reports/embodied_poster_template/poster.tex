\section{问题背景与动机}

多智能体机器人对抗不仅考验控制策略，也考验身体形态是否适合冲撞、防守和突破。
CompetEvo 将形态参数与控制策略共同优化，使智能体可以在竞争中“改造身体并学习打法”。

\structure{核心问题：} 在相同 MuJoCo robo-sumo 环境中，比较自进化/对抗进化与形态是否可优化对最终对抗能力的影响。

\begin{itemize}
  \item 固定形态只学习控制，容易受初始身体结构限制。
  \item 形态可优化时，动作同时包含形态向量与控制器动作。
  \item 对抗训练引入双策略非平稳性，可能带来更广探索，也可能产生强弱失衡。
\end{itemize}

\centering
\scriptsize
\caption{四个概念在实验中的操作化定义。}
\begin{tabularx}{\columnwidth}{@{}lY@{}}
\toprule
概念 & 实验含义\\

\bottomrule

\textbf{网络与训练框架。} 学习算法为 PPO，actor/critic 均为 MLP。训练分两阶段：
\begin{enumerate}
  \item Run-to-Goal：学习面向对手移动和基础接触能力；
  \item Robo-sumo：在相同观测/动作空间下更换奖励，学习推出、压制和防守。
\end{enumerate}

\textbf{优化目标。} 对每个智能体 $i$，策略 $\pi_i(\theta,\phi)$ 同时生成形态 $m_i$ 与控制动作 $a_i$，最大化折扣回报：
\[
J_i=\mathbb{E}_{\pi_i,M_i}\left[\sum_{t=0}^{T}\gamma^t R_i(s_t,a_t,m_i)\right],
\]
形态不优化组在 PPO loss 中屏蔽 $m_i$ 对应梯度。

\begin{itemize}
  \item 对抗训练曲线常出现先升后降：独立双策略造成非平稳对手，单轮训练胜率不等价于最终固定池能力。
  \item 自进化曲线更平滑；形态优化后，固定池积分与 reward margin 同时上升。
  \item delay200 在第 200 代后启用形态，但最终排名靠后，说明形态--控制早期协同很重要。
\end{itemize}

\section{结论}

\begin{enumerate}
  \item \textbf{形态优化是最关键因素。} Top 4 均为 morph 相关策略，且 fixed 组整体落后。
  \item \textbf{对抗进化提高上限，但需要处理双边失衡。} 独立策略探索更广，强者池表现最好的是 \agent{tp\_morph\_a0}；但固定形态对抗组出现 agent0/agent1 明显不平衡。
  \item \textbf{势均力敌的共同形态优化更稳。} 双方均可优化形态时，两名 agent 同时进入前四；只优化一方会强化主动方、削弱固定方。
\end{enumerate}

\structure{局限：} 本轮统计基于一个正式 seed 与 best checkpoint；训练曲线面对的对手分布不同，不能直接当作跨策略泛化指标。
