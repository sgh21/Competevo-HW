# 多智能体对抗中的形态与策略共同进化

数据来源：`reports/league/formal_best10_full_ep50_allpairs_color_video_seed901/report.html`、`leaderboard.csv`、`pairs.csv` 与本地论文 `ref_doc/paper.pdf`。

## 1. 问题背景与动机

具身智能中的机器人能力并不只由控制策略决定。对于需要冲撞、防守、突破和保持平衡的对抗任务，身体形态本身也会影响可学习策略的上限。传统多智能体对抗训练通常固定机器人形态，只优化控制器；CompetEvo 的核心问题则是：智能体能否在竞争中同时优化身体形态和对抗策略，从而获得更适合比赛的身体与打法。

本项目围绕 MuJoCo/Gymnasium 版本的 CompetEvo 环境，比较两类训练机制：自进化与对抗进化；同时比较两类身体设定：形态不优化与形态可优化。实验目标是验证三个假设：

1. 形态优化能显著提高最终对抗能力。
2. 对抗进化由于双策略非平稳性更强，可能探索更宽的状态空间，并学习到更鲁棒的策略。
3. 势均力敌的对手能促使智能体形成更主动、更激进的对抗行为；只优化一方时，上限可能提高，但另一方容易被压制。

## 2. 方法

### 概念定义

| 概念 | 本项目中的定义 |
| --- | --- |
| 自进化 | Agent 0 与 Agent 1 共享同一策略网络；Agent 1 通过 δ-Uniform 从 Agent 0 的历史策略池中采样。 |
| 对抗进化 | 两个智能体使用独立策略网络，权重不同，分别更新。 |
| 形态可优化 | 形态与控制策略同时优化；每个 episode 开始阶段采样一个形态并创建对抗环境。 |
| 形态不优化 | 形态固定；形态向量在 loss 计算时被 mask 掉，只更新控制动作相关参数。 |

### 网络结构

学习算法使用 PPO，策略网络和价值网络均为 MLP。观测输入包含三部分：机器人本体控制器状态、对方位置或相对状态、机器人形态信息。动作输出包含两部分：形态向量和控制器动作向量。对于形态不优化的设置，动作空间形式保持一致，但形态相关输出不参与有效优化。

这种设计使 fixed morphology 和 optimized morphology 可以在相同接口下训练和评估，差异集中在形态向量是否被允许影响环境构建与梯度更新。

### 训练策略

训练采用两阶段流程：

1. **Run-to-Goal 预训练**：智能体学习向目标方向移动、接近对手和保持基础运动稳定性。
2. **Robo-sumo 对抗训练**：观测空间和动作空间与第一阶段保持一致，但奖励函数切换为对抗奖励，强调推出对手、击倒对手和维持自身稳定。

两阶段使用相同策略接口，仅奖励函数不同。这样做的目的，是先让智能体具备基础运动能力，再进入稀疏胜负信号更强、非平稳性更高的对抗阶段。

在自进化中，策略通过 δ-Uniform 历史对手采样保持训练连续性，避免只面对最新策略导致模式坍缩。在对抗进化中，两个智能体各自维护独立策略，因而对手分布更动态，训练曲线更容易出现先升后降的“倒 S 型”现象。

## 3. 实验设计

### 任务设置

本实验共 6 组训练设置，产生 10 个参赛策略：

| 训练组 | 参赛策略 | 说明 |
| --- | --- | --- |
| 自进化 + 形态不优化 | `sp_fixed` | 共享策略，固定形态。 |
| 对抗进化 + 形态不优化 | `tp_fixed_a0`, `tp_fixed_a1` | 双策略，固定形态。 |
| 自进化 + 形态可优化 | `sp_morph` | 共享策略，形态与控制共同优化。 |
| 对抗进化 + 形态可优化 | `tp_morph_a0`, `tp_morph_a1` | 双策略，双方形态与控制共同优化。 |
| 对抗进化 + 一方形态优化、一方不优化 | `tp_mixed_a0_morph`, `tp_mixed_a1_fixed` | Agent 0 可优化形态，Agent 1 固定形态。 |
| 对抗进化 + 200 代后开始形态优化 | `tp_morph_delay200_a0`, `tp_morph_delay200_a1` | 前 200 代只学控制，之后启用形态优化。 |

### 积分赛协议

正式评测使用 10-agent 全循环赛：

| 项目 | 数值 |
| --- | ---: |
| 参赛 agent | 10 |
| unordered pair | 45 |
| fixture | 90 |
| 每个 fixture 局数 | 50 |
| 总局数 | 4500 |
| 评测 seed | 901 |
| 胜/平/负积分 | 4 / 1 / 0 |

每个 pair 进行双回合 slot-swap，降低左右场地和 agent slot 对结果的影响。视频只用于展示典型对局，完整胜负统计来自全部 4500 局。

### 综合排名规则

综合分由三部分组成：

| 指标 | 权重 | 含义 |
| --- | ---: | --- |
| 积分赛积分 | 50% | 10-agent 循环赛总积分归一化。 |
| Reward | 20% | 平均 episode reward 的 min-max 归一化。 |
| 大赛积分 | 30% | 与原积分榜前三名对局的每局积分归一化。 |

该规则避免只看胜负积分，也纳入 reward 强度和对强者池的直接表现。

## 4. 结果与分析

### 积分赛结果

| Rank | Agent | Points | Win rate | Avg reward | Reward margin |
| ---: | --- | ---: | ---: | ---: | ---: |
| 1 | `tp_mixed_a0_morph` | 1949 | 43.9% | 881.1 | 1214.8 |
| 2 | `tp_morph_a0` | 1885 | 43.1% | 968.3 | 1212.0 |
| 3 | `sp_morph` | 1841 | 43.7% | 964.1 | 972.5 |
| 4 | `tp_morph_a1` | 1767 | 36.9% | 349.9 | 609.7 |
| 5 | `sp_fixed` | 1585 | 34.6% | 509.2 | 375.6 |
| 6 | `tp_mixed_a1_fixed` | 1532 | 30.0% | 191.0 | 302.7 |
| 7 | `tp_fixed_a0` | 1521 | 34.7% | 408.0 | 85.9 |
| 8 | `tp_morph_delay200_a1` | 1080 | 23.0% | -230.9 | -1222.9 |

积分榜前三均为形态优化相关策略，前四也都来自形态可优化或形态优化混合训练。这直接支持“形态优化是关键因素”的结论。相比之下，固定形态的 `tp_fixed_a1` 排名垫底，且 reward margin 为 -2433.4，说明只优化控制器不足以弥补某些固定身体和对手分布带来的劣势。

| ---: | --- | ---: | ---: | ---: |
| 1 | `tp_morph_a0` | 98.36 | 2 | 1.740 |
| 2 | `tp_mixed_a0_morph` | 97.97 | 1 | 1.680 |
| 3 | `sp_morph` | 92.70 | 3 | 1.480 |
| 4 | `tp_morph_a1` | 83.03 | 4 | 1.437 |

| 7 | `tp_mixed_a1_fixed` | 69.44 | 6 | 1.103 |
| 8 | `tp_morph_delay200_a0` | 51.28 | 9 | 0.963 |
| 9 | `tp_morph_delay200_a1` | 49.00 | 8 | 0.870 |

原积分榜第一是 `tp_mixed_a0_morph`，综合榜第一变为 `tp_morph_a0`。原因是综合规则额外考虑 reward 和强者池对局：`tp_morph_a0` 的 avg reward 为 968.3，高于 `tp_mixed_a0_morph` 的 881.1；同时其对强者池每局大赛积分为 1.740，高于后者的 1.680。因此综合榜并非推翻积分榜，而是在“总体胜负 + 对局质量 + 强强对抗”三方面重新加权。

### 形态优化的作用

组级结果更清楚地体现形态优化的增益：

| Group | Best agent | Avg rank | Avg points | Avg win rate | Avg reward margin |
| --- | --- | ---: | ---: | ---: | ---: |
| `sp_morph` | `sp_morph` | 3.0 | 1841.0 | 43.7% | 972.5 |
| `tp_morph` | `tp_morph_a0` | 3.0 | 1826.0 | 40.0% | 910.9 |
| `tp_mixed_a0morph` | `tp_mixed_a0_morph` | 3.5 | 1740.5 | 36.9% | 758.7 |
| `sp_fixed` | `sp_fixed` | 5.0 | 1585.0 | 34.6% | 375.6 |
| `tp_fixed` | `tp_fixed_a0` | 8.5 | 1092.0 | 24.3% | -1173.8 |
| `tp_morph_delay200` | `tp_morph_delay200_a1` | 8.5 | 1072.5 | 23.2% | -1169.9 |

自进化条件下，`sp_morph` 比 `sp_fixed` 多 256 分，提升约 16.4%。对抗进化条件下，`tp_morph` 组均分 1826，显著高于 `tp_fixed` 组均分 1092，提升约 67.2%。这说明在更强非平稳对手下，身体形态的可塑性更重要。

### 对抗进化与双边失衡

对抗进化的优势在于上限更高。综合榜第一 `tp_morph_a0` 来自双策略形态优化，积分榜第一 `tp_mixed_a0_morph` 也来自对抗训练中的形态优化方。这说明独立策略对抗可以带来更强的探索压力，使 agent 学到更有攻击性的策略。

但对抗进化也会产生双边失衡。固定形态对抗组中，`tp_fixed_a0` 排第 7，而 `tp_fixed_a1` 排第 10；同一训练线的两个 agent 差异很大。混合形态组中，`tp_mixed_a0_morph` 排第 1，而固定形态的 `tp_mixed_a1_fixed` 排第 6，说明只给一方开放形态优化会明显强化可优化方。相比之下，双方都可优化形态的 `tp_morph_a0` 和 `tp_morph_a1` 分别排第 2 和第 4，整体更均衡。

### 训练曲线现象解释

训练曲线用于诊断学习过程，但不能直接替代固定池积分赛。原因是训练曲线面对的是当前训练对手或历史采样对手，而积分赛面对的是固定候选池中的所有策略。

从报告中的 MA9 平滑曲线看，对抗训练组常出现“先升后降”：例如 `tp_fixed` 的 eval win rate 在约 200 epoch 附近达到 0.65 左右，之后下降到 1000 epoch 附近的 0.10；`tp_morph` 也从早期 0.47 左右逐步下降到 0.26 左右。这种现象来自双策略共同更新造成的非平稳性：当一方暂时领先时，另一方会改变策略分布，原先有效的打法可能失效，因此训练胜率曲线不一定单调上升。

自进化曲线整体更平滑。`sp_fixed` 在中后期维持在约 0.55 到 0.64 的区间，符合共享策略与历史采样对手带来的相对平衡；`sp_morph` 则在后期稳定到约 0.74，说明形态优化不仅提高最终积分，也使自进化策略在训练评估中更稳定。

`tp_morph_delay200` 组在第 200 代后才开放形态优化，但最终两个 agent 排名第 8 和第 9。这表明“先控制、后形态”的课程设计在本轮实现中没有超过从早期就进行形态--控制协同优化的方案。可能原因是控制策略在前 200 代已经适配固定身体，后续形态变化反而需要重新协调动作与身体结构，导致有效训练时间不足。

### 关键结论对应证据

1. **形态优化是关键因素**：积分榜前四均为 morph 相关策略；`tp_morph` 组均分比 `tp_fixed` 高约 67.2%。
2. **对抗进化更有上限但更不稳定**：综合榜第一与积分榜第一都来自对抗训练，但对抗组内部 agent0/agent1 容易产生能力差异。
3. **势均力敌的对手促进更均衡策略**：双方均形态优化的 `tp_morph_a0/a1` 同时进入前四；一方形态优化时，可优化方极强，固定方明显落后。

## 5. 结论

本项目通过 6 组训练、10 个策略和 4500 局固定池循环赛，验证了多智能体对抗环境中形态--控制共同优化的重要性。实验显示，形态优化显著提高策略上限；对抗进化能够形成更强的攻击性和强者池表现；但对抗进化也带来非平稳训练和双边能力失衡，需要通过对手采样、形态约束或更稳定的课程设计进行控制。

最终结果表明，在机器人对抗任务中，身体不是控制策略的静态载体，而是策略的一部分。更强的 agent 往往不是单纯“学会更好动作”，而是同时学会“长成更适合对抗的身体”并围绕该身体形成战术。

当前局限包括：本轮正式评测主要基于一个 seed 和 best checkpoint；训练曲线与积分赛面对的对手分布不同；实验集中在当前 dev-ant/robo-sumo 设置，尚未系统比较 ant、bug、spider 等跨物种形态。后续可扩展多 seed 统计、任意 checkpoint 混合评测，并分析最终形态参数与具体攻防行为之间的对应关系。
