分析

1. 自博弈路线明显更稳定，尤其是 sp-morph。形态优化让 agent0 在最终外部评测中比 sp-fixed 多出约 167.5 平均回报，并把对手胜率从 0.20 压到 0.06。

2. 双人博弈最终 checkpoint 的表现更依赖博弈状态。tp-fixed 的外部平局率达到 0.76，说明双方最终策略较多进入僵持；tp-morph 的双方胜率更均衡，但同样有 0.54 平局。

3. 混合模式符合预期方向：agent0 形态优化、agent1 固定形态时，agent0 外部评测胜率 0.30，高于 agent1 的 0.06，平均回报优势约 2403。但 0.64 平局率说明它还没有形成稳定终结优势。

4. 训练中 best 指标普遍高于最终指标，尤其双人博弈更明显。后续如果用于展示或 league 评测，建议同时保留 best.p 和 epoch_1000.p，不要只看最终 epoch。

稳定性记录：tp-morph 原始长训在 epoch 827 后发生一次 segmentation fault，后续又在 epoch 983 采样阶段卡住；tp-mixed-a0morph 在 epoch 912 采样阶段卡住。两者均从最近完整 checkpoint 恢复并补齐到 epoch 1000。建议后续长训按 100-200 epoch 分段运行，或给采样 worker 加 watchdog/retry，降低单次长进程风险。

确定性胜率评测

选择一个兼容配置来决定 slot0/slot1 是否采样形态动作：两边固定形态用 tp-fixed/config.yml；两边形态优化用 tp-morph/config.yml；slot0 形态优化、slot1 固定形态用 tp-mixed-a0morph/config.yml。然后把两个 agent 的 checkpoint 分别传入。

conda run -n EAI python scripts/evaluate_checkpoint.py \
  --cfg <compatible_config.yml> \
  --ckpt_dir <fallback_models_dir> \
  --agent0_ckpt_dir <run_A>/models \
  --agent0_ckpt epoch_1000 \
  --agent1_ckpt_dir <run_B>/models \
  --agent1_ckpt best \
  --episodes 100 \
  --seed 20260605 \
  --out reports/unified_modes/eval/custom_A_vs_B.json

self-play run 的 checkpoint 直接位于 models/epoch_1000.p；two-player run 的 checkpoint 位于 models/agent_0/... 和 models/agent_1/...。当前评测脚本会同时兼容这两种目录结构。
